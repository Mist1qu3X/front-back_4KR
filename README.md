# Практические работы 19-24

**Дисциплина:** Фронтенд и бэкенд разработка  
**Институт:** ИПТИП  
**Кафедра:** Индустриального программирования  
**Преподаватель:** Краснослободцева Д.Б.


## Технологии

- Node.js + Express
- PostgreSQL 15 + Sequelize ORM
- Redis 7 (кэширование)
- Nginx (балансировка, Round Robin)
- HAProxy (балансировка, Round Robin)
- Docker + Docker Compose

## Что сделано

**Практика 19** — Подключил PostgreSQL через Sequelize, создал модель User с полями first_name, last_name, age, created_at, updated_at.

**Практика 20** — Работа с базами данных (объединена с практикой 19).

**Практика 21** — Добавил кэширование через Redis. GET-запросы кэшируются на 60 секунд. При создании/обновлении/удалении кэш сбрасывается.

**Практика 22** — Настроил балансировку нагрузки через Nginx (порт 80) и HAProxy (порт 8080). Три backend-сервера, Round Robin, резервный сервер, отказоустойчивость.

**Практика 23** — Всё упаковал в Docker. Проект запускается одной командой docker compose up.

**Практика 24** — Итоговая сборка и README.

## Архитектура

Есть три backend-сервера (на разных портах), перед ними два балансировщика — Nginx и HAProxy. Сзади PostgreSQL для хранения данных и Redis для кэша. Всё в Docker-контейнерах, общаются через внутреннюю сеть.

# API

- `POST /api/users` — создать пользователя
- `GET /api/users` — список пользователей (кэш 60с)
- `GET /api/users/:id` — пользователь по ID (кэш 60с)
- `PATCH /api/users/:id` — обновить пользователя
- `DELETE /api/users/:id` — удалить пользователя
